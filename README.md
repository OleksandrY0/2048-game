# 2048 Game

This project is a browser-based implementation of the classic **2048 game**.
The game logic is encapsulated in a `Game` class that manages the board state, score, and game status.

---

## 🎮 Demo

[DEMO LINK](https://oleksandry0.github.io/2048-game/)

---

## 🛠 Technologies Used

- JavaScript (ES6+)
- HTML5
- CSS / SCSS
- DOM manipulation

---

## 🧠 Game Logic Overview

The core logic is implemented in the `Game` class:

- Stores the game board as a 4×4 matrix
- Handles moves in all directions (left, right, up, down)
- Merges tiles according to 2048 rules
- Generates random tiles (2 or 4)
- Tracks the current score
- Detects win and lose conditions

---

## ✨ Features

- Classic 2048 gameplay
- Score calculation
- Win detection (2048 tile)
- Lose detection (no available moves)
- Restart and start functionality
- Clean and modular game logic
